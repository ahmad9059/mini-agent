# Phase 2 - Scaffold and Discover Skills

Depends on: Phase 1 sign-off

Status: **Complete.** Implemented and verified on Node.js 20 and Node.js 26.

---

## 1. Goal

Create the minimal Node.js project and implement the specification-facing skill loader. At the end of this phase, valid skills can be discovered and represented as metadata without reading their instruction bodies into the catalog.

## 2. Scope

### In Scope

- ESM package setup for Node 20+.
- YAML frontmatter parsing.
- Direct-child discovery under project `.skills/`.
- Strict validation for fields used by the specification.
- Metadata-only catalog generation.
- Unit tests for valid and invalid skill packages.

### Out of Scope

- Anthropic API calls.
- Skill selection.
- Bundling the final three production skills.
- User-level or `.agents/skills/` discovery.
- Running scripts or loading referenced resources.

## 3. Detailed Tasks / Design

1. Add `package.json` with `type: module`, Node engine, scripts, and only the dependencies needed by the final project.
2. Add `.gitignore` for dependencies, coverage, logs, and local environment files.
3. Implement `discoverSkills(skillsDirectory)` using `fs/promises.readdir({ withFileTypes: true })` and deterministic name sorting.
4. Implement frontmatter parsing that:
   - Requires opening and closing `---` delimiters.
   - Parses YAML as a mapping.
   - Separates metadata from the Markdown body.
   - Discards the body after discovery so catalog entries retain metadata only.
5. Validate required and optional fields used by the spec:
   - `name`: 1-64 characters, lowercase alphanumeric plus single hyphens, no edge/consecutive hyphens, matches parent directory.
   - `description`: non-empty, maximum 1024 characters.
   - `compatibility`: string, maximum 500 characters when present.
   - Unknown top-level frontmatter fields: reject to match the reference validator.
6. Return `{ name, description, location }` records and aggregate diagnostics with file paths.
7. Implement catalog formatting as a compact `<available_skills>` XML block containing only metadata.

- [x] `npm install` succeeds on Node 20+.
